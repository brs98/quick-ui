QuickUI 0.2.0 makes the component library easier to install, design with, and maintain.

- Install `quickui`, `quickbook`, and a desktop launcher with `python3 scripts/install.py` from the source archive. Reinstalling protects edited installation files; uninstalling preserves projects and saved designs.
- Quickbook restores your design and browsing preferences. Save named presets and Omarchy recipes locally, then open, rename, or delete them in the native app.
- Review component changes with `quickui diff`. `quickui update` updates pristine copied sources, while customized sources stay yours. Optional merge proposals are separate files for review.
- Preview an Omarchy theme and export its follow settings without making the core library depend on Omarchy.
- Native CI runs Python, QML, interaction, accessibility, application, persistence, and installed-consumer checks. Tagged releases include a reproducible source archive and SHA-256 checksum.

Requirements: Python 3.8+; Quickshell and Qt 6.10+ Quick Controls for native previews. The current native test platform is Arch Linux with Quickshell 0.3.1 and Qt 6.11.2. Other distributions/compositors have not yet received the same coverage.

Download `quick-ui-0.2.0.tar.gz` and `SHA256SUMS`, check with `sha256sum -c SHA256SUMS`, extract the archive, then run `python3 scripts/install.py` inside it. No Git checkout is needed to install or run that archive. Ensure `~/.local/bin` is on PATH, then open Quickbook from your application launcher or run `quickbook`.

See the [starter guide](https://github.com/brs98/quick-ui/blob/v0.2.0/docs/getting-started.md) for your first shell and the [update guide](https://github.com/brs98/quick-ui/blob/v0.2.0/docs/updates.md) before updating customized components.
